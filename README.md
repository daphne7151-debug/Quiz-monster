# 몬스터 배틀

초등 수학·사회·과학·영어·한국어 학습 게임 (웹에서 바로 실행).

- 대결 모드(2·4·6명)와 협동 모드(1~6명, 보스 7스테이지 / 단축 4스테이지)
- 과목: 수학, 사회, 과학, 영어, 한국어

## 배포 방법 (GitHub Pages)
1. 이 폴더의 파일을 저장소에 업로드합니다.
2. Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 정하고 Save.
3. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 에서 실행됩니다.
